# تهویه تبریز — کاتالوگ وب

وب‌سایت استاتیک فارسی/RTL برای معرفی دسته‌بندی تجهیزات تهویه و استعلام قیمت.

## ساختار
- `index.html` — صفحه اصلی
- `assets/styles.css` — طراحی واکنش‌گرا و انیمیشن‌های سبک
- `assets/app.js` — جست‌وجو، فیلتر، منوی موبایل و تعامل‌ها
- `functions/api/contact.js` — API عمومی تماس، شماره را از متغیر محیطی می‌خواند

## اجرای محلی
می‌توانید `index.html` را باز کنید، اما برای تست API تماس باید سایت را روی Cloudflare Pages اجرا کنید؛ چون API با باز کردن فایل محلی کار نمی‌کند.

## انتشار در Cloudflare Pages
1. مخزن GitHub را **Private** نگه دارید.
2. در Cloudflare Dashboard وارد **Workers & Pages → Create → Pages → Connect to Git** شوید (نام گزینه‌ها ممکن است تغییر کند).
3. مخزن خصوصی را انتخاب کنید. اگر Cloudflare امکان اتصال مخزن خصوصی را در حساب شما نداد، مخزن را Public نکنید؛ از روش جایگزین با دسترسی خصوصی/آپلود مستقیم استفاده کنید.
4. چون سایت HTML/CSS/JS خالص است، Build command را خالی بگذارید و Build output directory را `.` (ریشه پروژه) قرار دهید.
5. بعد از اولین Deploy، در تنظیمات پروژه به **Settings → Variables and Secrets** بروید و یک متغیر با نام `PHONE_NUMBER` بسازید و شماره تماس فروشگاه را در مقدار آن قرار دهید. مقدار را در GitHub، README یا فایل‌های سایت ننویسید.
6. پروژه را دوباره Deploy کنید. تابع `functions/api/contact.js` در مسیر `/api/contact` اجرا می‌شود.
7. سایت عمومی است، اما مخزن اصلی خصوصی می‌ماند. شماره تماس برای بازدیدکنندگان سایت قابل مشاهده خواهد بود؛ این رفتار برای شماره تماس عمومی طبیعی است.

## نکات
- هیچ توکن، رمز یا کلید API در این پروژه وجود ندارد.
- قیمت‌ها عمداً درج نشده‌اند و باید استعلام شوند.
- تصاویر در نسخه فعلی از Unsplash بارگیری می‌شوند؛ بنابراین برای نمایش آن‌ها اینترنت لازم است و تصاویر در پوشه محلی ذخیره نشده‌اند. پیش از انتشار تجاری، مجوز هر تصویر را بررسی یا تصاویر دارای مجوز مناسب را جایگزین کنید.
- تصاویر نمونه محیط‌های فنی هستند و لزوماً عکس دقیق هر SKU/مدل محصول نیستند؛ آن‌ها را به‌عنوان مشخصات فنی قطعی محصول تلقی نکنید.
- ساعات کاری عمداً درج نشده، چون تأیید نشده است.
- لینک استعلام محصولات به تلگرام فروشگاه می‌رود؛ متن محصول در پیام خودکار وارد نمی‌شود. هنگام پیام، نام محصول را همراه مشخصات بفرستید.

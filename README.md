# پروژه وب‌سایت «تهویه تبریز» (کانال تهویه تبریز)
### مرکز تخصصی تجهیزات تهویه و کانال‌سازی صنعتی

---

## ۱. معرفی پروژه
این پروژه یک وب‌سایت شرکتی و کاتالوگ صنعتی مدرن و سبک برای فروشگاه **تهویه تبریز** است. طراحی بر اساس پالت رنگی مشکی زغالی صنعتی، استیل متالیک و قرمز کنترل‌شده انجام گرفته و از زبان فارسی و چینش RTL به طور کامل پشتیبانی می‌کند.

### ویژگی‌های کلیدی:
- **کاتالوگ جامع و واقعی:** ۱۹ قلم کالای واقعی شامل کانال اسپیرال، اتصالات، انواع دریچه‌های هوا، هواکش‌های سانتریفیوژ، لوله‌های فلکسیبل و عایق‌های الاستومری.
- **جست‌وجوی فوری و بدون وقفه (Instant Live Search):** جستجو بر اساس نام فارسی، عنوان انگلیسی و ویژگی‌های قطعات.
- **فیلتر تب‌دار دسته‌بندی‌ها:** دسترسی آسان و سریع به گروه‌های مختلف کالا.
- **سیستم استعلام قیمت روز:** دکمه‌های استعلام مستقیم تلگرامی با پیش‌نویس خودکار و برقراری تماس تلفنی.
- **مدیریت ایمن اطلاعات تماس و شماره تلفن:** شماره تماس در فایل‌های سورس پروژه و مخزن گیت‌هاب ذخیره نمی‌شود و از طریق متغیر محیطی سرویس میزبانی (Cloudflare Pages Environment Variable) به صورت پویا تامین می‌گردد.
- **خودکفایی و سرعت بالا:** تمام تصاویر بهینه‌سازی شده در فرمت WebP و فونت‌های استاندارد فارسی به صورت محلی در پروژه قرار دارند و سایت وابسته به CDN خارجی نیست.

## ۳. دستورالعمل انتشار روی Cloudflare Pages (روش استاندارد با مخزن Private)

با این روش، مخزن اصلی شما در گیت‌هاب **۱۰۰٪ خصوصی (Private)** باقی می‌ماند و کدهای سایت فقط برای خودتان قابل دسترسی خواهند بود، در حالی که سایت به صورت عمومی در سراسر اینترنت با بالاترین سرعت و امنیت منتشر می‌شود.

### گام اول: ساخت مخزن خصوصی در GitHub
1. وارد حساب کاربری خود در [GitHub](https://github.com) شوید.
2. روی دکمه **New repository** کلیک کنید.
3. یک نام برای مخزن انتخاب کنید (مثلاً `tahvieh-tabriz`).
4. **بسیار مهم:** گزینه **Private** را انتخاب کنید تا مخزن شما خصوصی باشد و عموم به آن دسترسی نداشته باشند.
5. فایل‌های پروژه را به مخزن Commit و Push کنید:
   ```bash
   git init
   git add .
   git commit -m "feat: initial release of Tahvieh Tabriz"
   git branch -M main
   git remote add origin https://github.com/USERNAME/tahvieh-tabriz.git
   git push -u origin main
   ```

### گام دوم: اتصال به Cloudflare Pages
1. وارد داشبورد [Cloudflare](https://dash.cloudflare.com) شوید.
2. از منوی کناری به بخش **Compute (Workers) > Workers & Pages** یا **Pages** بروید.
3. روی دکمه **Create application** و سپس سربرگ **Pages** کلیک کنید.
4. گزینه **Connect to Git** را بزنید و حساب GitHub خود را متصل نمایید.
5. مخزن خصوصی خود (`tahvieh-tabriz`) را از لیست مخازن Private انتخاب کنید.
6. در بخش تنظیمات Build:
   - **Framework preset:** `None`
   - **Build command:** خالی بگذارید (پروژه استاتیک بدون نیاز به بیلد است).
   - **Build output directory:** خالی یا `.` (محتوای ریشه پروژه).

### گام سوم: ثبت متغیر محیطی شماره تماس (PHONE_NUMBER)
برای اینکه شماره تماس فروشگاه بدون هاردکد شدن در کدها روی سایت کار کند:
1. در مراحل ساخت پروژه (یا پس از ساخت در مسیر **Settings > Environment variables**):
2. در بخش **Production** روی دکمه **Add variable** کلیک کنید:
   - **Variable name:** `PHONE_NUMBER`
   - **Value:** شماره تماس مورد نظرتان را وارد نمایید.
3. روی دکمه **Save and Deploy** کلیک کنید.
4. پس از چند لحظه، پروژه منتشر شده و یک دامنه اختصاصی رایگان (مانند `tahvieh-tabriz.pages.dev`) دریافت می‌کنید. همچنین می‌توانید دامنه اختصاصی خودتان را نیز به آن متصل کنید.

## ۴. روش جایگزین (Direct Upload یا سایر پلتفرم‌ها)

چنانچه در حساب خود به اتصال گیت‌هاب دسترسی ندارید:
1. در پنل Cloudflare Pages گزینه **Direct Upload** را انتخاب کنید.
2. پوشه خروجی را به صورت یک فایل ZIP آپلود کنید.
3. در بخش **Settings > Environment variables** متغیر `PHONE_NUMBER` را ایجاد کنید.
4. در صورتی که هاست اشتراکی سنتی استفاده می‌کنید، می‌توانید یک فایل PHP کوچک یا تنظیمات ساده در روت بسازید تا اندپوینت `/api/contact` را با فرمت JSON بازگرداند.

---

## ۵. اجرای محلی پروژه و تست توسعه (Local Dev)

برای اجرای پیش‌نمایش در سیستم محلی خود:
```bash
# اجرای مستقیم با Node.js
node server.js
```
سپس مرورگر خود را باز کرده و به آدرس `http://localhost:3000` مراجعه فرمایید. در این حالت سرور لوکال متغیرهای محیطی و مسیر `/api/contact` را شبیه‌سازی می‌کند.
